# E-Voting System

A web-based E-Voting System developed using ASP.NET (C#) and SQL Server. The system provides a digital platform for voter registration, authentication, candidate management, online voting, and election result management.

## Features

- Voter registration and login
- Admin login and dashboard
- Candidate management
- Online voting
- Vote validation
- Election result management
- Candidate-wise vote reports
- Voter dashboard
- Political party images
- Result and voting reports

## Modules

### Admin Module
- Admin login
- Manage candidates
- View voting information
- View election reports
- Manage election results

### Voter Module
- Voter registration
- Voter login
- Voter dashboard
- View candidates
- Cast vote
- View results

How to Run
Clone or download this repository.
Open the .csproj file in Visual Studio.
Configure the SQL Server database.
Update the database connection settings in Web.config if required.
Build the project.
Run the application using Visual Studio.
Project Role

Developer & Tester

Responsibilities included developing the web application, implementing voting-related functionality, testing modules, and identifying and fixing application issues.

Purpose

The main purpose of this project is to provide an electronic voting platform that simplifies the voting process and helps manage voters, candidates, votes, and election results digitally.
